
# Array Operations and Searching Techniques Using Python

## About the Project
This is a menu-driven Python mini project that performs searching and basic operations on a list of integers.

## Features
- Linear Search
- Binary Search
- Reverse Array
- Find Maximum and Minimum
- Calculate Sum of Array Elements
- Display Array
- Exit Option

## Concepts Used
- Python Lists
- Functions
- Loops
- Conditional Statements
- User Input
- List Slicing
- Built-in Functions

## Requirements
- Python 3.x
- Visual Studio Code or any Python editor

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `array_operations.py`.
4. Enter the array elements and choose an operation from the menu.
